This project uses Ultralytics, PyTorch, torchvision, OpenCV, Matplotlib, and other packages listed in requirements-lock.txt. Each retains its own license.

Ultralytics provides AGPL-3.0 and commercial licensing options. Review https://www.ultralytics.com/license before distributing a project using its software or weights. No license for the original scripts in this repository has been selected yet; select an appropriate project license before presenting it as open-source.

The local Roboflow dataset configuration identifies the source as:
https://universe.roboflow.com/honors-thesis-rsqz3/pfm-1-all-images-ivhiv/dataset/2
